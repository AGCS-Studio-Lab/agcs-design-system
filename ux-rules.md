# UX rules moved to agcs-ui

The UX and accessibility rules for AGCS product apps moved to
[AGCS-Studio-Lab/agcs-ui/ux-rules.md](https://github.com/AGCS-Studio-Lab/agcs-ui/blob/main/ux-rules.md)
on 2026-09-24, as v4. The color and grid rules for apps live next to them, in
`agcs-ui/docs/color.md` and `agcs-ui/docs/grid.md`.

This repo keeps the brand. Where a rule in agcs-ui meets a brand rule here,
the brand rule stands; agcs-ui lists the scoped exceptions for apps.
